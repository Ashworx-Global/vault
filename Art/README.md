# Art & Investigations

A curated collection of design explorations, studies, and creative investigations. Each folder contains notes on the process and thinking behind the work.

> **🔒 Images are watermarked to prevent AI training use. Right-click save is disabled on the web.**

## Quick Start

**[📖 Read the full setup guide →](SETUP.md)**

Each art project folder contains:
- **README.md** — Journal notes, process notes, what you were exploring
- **source/** — Original PSD/Krita files (kept private, auto-converted to PNG)
- **exports/** — High-resolution images (published with watermark)

## Adding Your First Project

1. Create folder: `Art/your-project-name/`
2. Create subfolders: `source/` and `exports/`
3. Add `README.md` with your process notes
4. Add PSD files to `source/` (auto-converts) OR PNG files to `exports/`
5. Run: `python3 scripts/build-site.py`
6. Push to GitHub — done!

```
Art/my-design-study/
├── README.md (your notes)
├── source/ (Photoshop/Krita files)
└── exports/ (generated PNGs)
```

## Features

✅ **Auto-convert PSDs** → High-res PNG at 300 DPI  
✅ **Watermark** → `© Not for AI Training • Original Art`  
✅ **Right-click protection** → Prevents casual saving  
✅ **Lightbox gallery** → Click to enlarge, keyboard navigation  
✅ **Journal notes** → Write process reflections in README.md  
✅ **Modern grid** → Responsive layout matching site style
